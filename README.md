# About me

コーディングを中心に約20年の実務経験があります。実務の制作物は守秘義務のため非公開としております。  
2025年のiDeCo開設時に制度を調べた際複数のWebサイトや動画を横断する必要があり時間を要した経験から会社員向けのiDeCo制度解説サイト「ideco-navi」を企画・制作しました。React／TypeScriptで実装しmicroCMSで記事を管理しています。公開後はGA4とASP広告タグを設置して運用・収益化にも取り組み構成案や原稿作成の一部でAIを活用しています。

またReactの学習の一環としてFirebase認証とデータ保存に対応したメモアプリ「memo2-app」を制作しました。
